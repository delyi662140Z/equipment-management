# 电机车间设备管理系统

面向电机车间设备管理场景的规范化文档与工具集，覆盖设备台账、点检、保养、维修、备件库存及安全管理六大模块。

## 项目背景

本项目服务于电机车间日常设备管理实践。车间配备约 20 名维修人员，管理对象包括电机、减速机、风机、泵类、起重设备、配电柜及配套产线设备。项目目标是：

1. 将设备资料从分散的纸质记录与 Excel 表格迁移至统一的版本化管理仓库；
2. 建立可追溯的点检、保养、维修记录规范；
3. 沉淀备件库存与申请流程，降低停机待料时间；
4. 固化设备安全管理要求，确保点检与作业有据可依。

## 功能模块

| 模块 | 目录 | 说明 |
|---|---|---|
| 设备台账 | `docs/设备台账/` | 设备基础信息、编号规则、技术参数归档 |
| 点检资料 | `docs/点检资料/` | 日常点检表、周期点检标准、异常上报流程 |
| 保养资料 | `docs/保养资料/` | 保养计划、保养作业指导书、记录模板 |
| 维修管理 | `docs/维修管理/` | 维修工单、故障代码对照、疑难问题处理记录 |
| 备件库存 | `docs/备件库存/` | 备件清单、库存台账、采购申请流程 |
| 安全管理 | `docs/安全管理/` | 作业安全规范、危险源清单、应急预案 |

## 设备编号规则

设备编号统一采用 `类别-区域-序号` 格式：

```
示例：MTR-A-001
│     │   └─ 三位序号，从 001 起编
│     └───── 区域代码，A/B/C 表示车间区域
└─────────── 类别代码，MTR=电机, RED=减速机, FAN=风机,
            PMP=泵, CRM=起重设备, ELC=配电柜, OTH=其他
```

编号一经分配不得变更。设备报废后编号作废，不复用。

## 技术约定

- 文档编码：UTF-8
- 换行符：LF
- 表格：Markdown 标准表格语法
- 日期格式：`YYYY-MM-DD`
- 数值单位：公制单位（mm、kg、kW、℃、MPa）

## 适用边界

本项目沉淀的是**管理流程与文档模板**，不包含以下专业内容：

- 设备电气原理图、机械装配图（由 CAD / SolidWorks 单独维护，仓库仅记录图号索引）；
- PLC 程序源码（三菱 PLC 程序由专用软件管理，仓库仅记录程序版本与变更说明）；
- 涉及企业保密的生产工艺参数。
