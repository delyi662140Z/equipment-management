# 安全管理

记录车间设备作业的安全规范、危险源清单及应急处置预案。

## 基本要求

1. 所有设备作业必须遵守企业安全管理制度与国家相关法规；
2. 维修作业前须完成能量隔离（断电、挂牌、上锁）；
3. 特种作业（起重、电气、高处）须由持证人员执行；
4. 作业人员须正确佩戴劳动防护用品。

## 危险源清单

| 危险源 | 可能后果 | 控制措施 |
|---|---|---|
| 旋转部件 | 机械伤害 | 防护罩完好，检修前停机挂牌 |
| 高压电气 | 触电 | 断电验电，使用绝缘工具 |
| 高温表面 | 烫伤 | 冷却后作业，佩戴隔热手套 |
| 起重作业 | 物体打击 | 持证操作，警戒区隔离 |
| 油液泄漏 | 滑倒、火灾 | 及时清理，配置吸油材料 |
| 噪声 | 听力损伤 | 佩戴耳塞/耳罩 |

## 作业许可

以下作业须办理作业许可证后方可实施：

- 动火作业
- 高处作业（2 米及以上）
- 有限空间作业
- 临时用电
- 设备大修涉及的系统隔离

## 应急处置

- **触电**：立即切断电源，使用绝缘物使伤者脱离电源，禁止直接用手拉拽，同时呼叫急救；
- **机械伤害**：立即停机，禁止强行拔出异物，包扎止血后送医；
- **火灾**：切断电源与气源，使用对应类型灭火器，火势失控立即撤离并报警；
- **油液泄漏**：围堵、吸附、收集，禁止直接用水冲洗。

## 文件组织

- `安全作业规范.md` — 各类设备作业的安全操作步骤
- `危险源清单.md` — 危险源辨识与风险分级
- `应急预案.md` — 各类突发事件的处置流程

## 培训要求

新员工上岗前须完成车间安全培训；维修人员每年参加不少于一次安全再培训，培训记录留档。
