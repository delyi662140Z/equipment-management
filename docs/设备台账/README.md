# 设备台账

记录车间所有设备的基础信息，是点检、保养、维修、备件管理的数据基础。

## 台账字段

每台设备必须记录以下信息：

| 字段 | 说明 |
|---|---|
| 设备编号 | 按 `类别-区域-序号` 规则分配，唯一且不可变更 |
| 设备名称 | 标准名称，与铭牌一致 |
| 设备类别 | 电机/减速机/风机/泵/起重设备/配电柜/其他 |
| 型号规格 | 铭牌型号及关键参数 |
| 制造商 | 生产厂家全称 |
| 出厂编号 | 厂家序列号 |
| 安装位置 | 车间区域及具体工位 |
| 投用日期 | `YYYY-MM-DD` |
| 额定参数 | 功率、电压、电流、转速等 |
| 图纸索引 | CAD/SolidWorks 图号，实际图纸离线保管 |
| 状态 | 在用/停用/报废 |

## 文件组织

每台设备一个独立 Markdown 文件，文件名格式：`设备编号-设备名称.md`。

示例：`MTR-A-001-三相异步电机.md`

## 变更管理

- 设备参数变更需更新台账并注明变更日期与原因；
- 设备报废后标记为「报废」，编号作废不复用；
- 新增设备须在投用后 3 个工作日内完成台账登记。
