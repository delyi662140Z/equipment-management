# 备件库存

记录设备备件清单、库存台账及采购申请流程。

## 备件分类

| 类别 | 示例 |
|---|---|
| 电气类 | 接触器、继电器、断路器、变频器、轴承 |
| 机械类 | 齿轮、联轴器、密封件、油封 |
| 润滑类 | 润滑油、润滑脂 |
| 易耗类 | 保险丝、滤芯、皮带 |

## 备件清单字段

| 字段 | 说明 |
|---|---|
| 备件编号 | 唯一编号 |
| 备件名称 | 标准名称 |
| 型号规格 | 完整型号 |
| 适用设备 | 关联设备编号，可多台 |
| 单位 | 个/套/千克/升 |
| 安全库存 | 最低库存警戒线 |
| 存放位置 | 货架/库位编号 |
| 供应商 | 主要采购渠道 |

## 库存管理

- 每次领用后更新库存台账，注明领用日期、用途、关联工单；
- 库存低于安全线时发起采购申请；
- 每季度盘点一次，账实不符须查明原因并调整。

## 文件组织

- `备件清单.md` — 所有备件的基础信息
- `库存台账.md` — 实时库存数量与出入库记录
- `采购申请/` — 按 `REQ-YYYYMMDD-序号.md` 命名的申请单

## 采购申请流程

1. 维修人员或设备主管填写采购申请，说明备件、数量、用途、紧急程度；
2. 设备主管审核；
3. 提交采购部门执行；
4. 到货验收后更新库存台账并关闭申请。
