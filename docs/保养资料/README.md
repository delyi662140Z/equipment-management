# 保养资料

记录设备保养计划、作业指导书及实际保养完成情况。

## 保养分类

| 级别 | 周期 | 主要内容 |
|---|---|---|
| 一级保养 | 月度 | 清洁、紧固、润滑、外观检查 |
| 二级保养 | 季度 | 一级保养内容 + 内部检查、油液更换 |
| 三级保养 | 年度 | 二级保养内容 + 精度检查、关键部件更换 |

## 保养计划制定

- 每年 12 月制定下一年度保养计划；
- 计划按设备编号排布，明确保养级别、执行月份与负责人；
- 计划变更须经设备主管批准并记录原因。

## 文件组织

- `保养计划/` — 年度、季度保养排程
- `保养指导书/` — 各类设备的保养作业步骤
- `保养记录/` — 按 `YYYY-MM-DD-设备编号-保养.md` 命名的实际记录

## 记录要求

每次保养完成后须记录：

- 保养日期、设备编号、执行人
- 保养级别与作业内容
- 更换的备件名称与数量（同步更新备件库存）
- 发现的问题及处理结果
- 下次保养计划日期
