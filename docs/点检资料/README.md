# 点检资料

记录设备日常与周期点检的标准、表单及异常处理流程。

## 点检分类

| 类型 | 周期 | 执行人 | 记录方式 |
|---|---|---|---|
| 日常点检 | 每班 | 操作工 | 班前点检表 |
| 周点检 | 每周 | 维修工 | 周点检记录表 |
| 月点检 | 每月 | 维修工 | 月点检记录表 |
| 专项点检 | 按需 | 设备主管 | 专项检查表 |

## 标准点检项目

- **电机**：温升、电流、振动、异响、轴承状态、接线端子、接地
- **减速机**：油位、油温、泄漏、异响、密封
- **风机/泵**：振动、噪声、泄漏、流量、轴承温度
- **起重设备**：制动器、限位器、钢丝绳、吊钩、安全装置
- **配电柜**：指示仪表、接线端子温升、异味、接地、灭弧装置

## 文件组织

- `点检标准/` — 各类设备的点检项目与判定标准
- `点检记录/` — 按 `YYYY-MM-区域-点检表.md` 命名的实际记录

## 异常处理

1. 点检发现异常立即记录，并上报设备主管；
2. 判定为重大隐患的，立即停机并挂设警示牌；
3. 一般异常纳入维修工单，在 `../维修管理/` 中跟踪闭环。
