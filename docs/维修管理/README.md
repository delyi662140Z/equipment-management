# 维修管理

记录设备故障维修工单、故障案例与疑难问题处理过程。

## 维修工单流程

```
故障上报 → 工单登记 → 故障诊断 → 维修处理 → 试车验证 → 工单关闭
```

## 工单字段

| 字段 | 说明 |
|---|---|
| 工单编号 | `WO-YYYYMMDD-序号` |
| 设备编号 | 关联设备台账 |
| 故障现象 | 客观描述，含发生时间与工况 |
| 故障诊断 | 原因分析与判断依据 |
| 处理措施 | 具体作业内容、更换备件 |
| 维修人员 | 参与人员 |
| 工时 | 实际维修工时 |
| 验证结果 | 试车运行情况 |
| 关闭日期 | 工单闭环时间 |

## 文件组织

- `维修工单/` — 按工单编号命名的维修记录
- `故障案例库/` — 典型故障的处理方法与经验沉淀
- `疑难问题/` — 需专家支持或反复出现的复杂问题记录

## 故障分类

- **电气故障**：绕组、绝缘、接线、变频器、PLC 相关
- **机械故障**：轴承、齿轮、联轴器、密封、传动相关
- **润滑故障**：油位异常、油质劣化、润滑点失效
- **外力损伤**：碰撞、异物进入、误操作

## 案例沉淀要求

重复性故障、处理时间超过 4 小时的故障、涉及特殊工具的故障，须在工单关闭后整理为案例纳入 `故障案例库/`。
